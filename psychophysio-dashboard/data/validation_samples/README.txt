Validation fixtures (PsyPhy Datalab)
==================================

BrainVision (.vhdr + .eeg)
--------------------------
Generated by generate_bv_fixtures.py. Recreate them with:

    python data/validation_samples/generate_bv_fixtures.py

  bv_val_ok       — channels 65–68 look fine (expect a green summary).
  bv_val_flat     — last four channels are zero (expect a "flat signal" warning).
  bv_val_warn_fs  — sampling rate is 40 Hz (expect an unusual-Fs warning).

In the app: signal source → BrainVision → pick the file from the list.

Transcript (.json)
------------------
In the sidebar, turn on "load transcript from file" and select the file.

  transcript_ok_short_session.json    — OK on a short recording (~8 s), e.g. bv_val_ok.
  transcript_ok_hour_demo.json        — OK in the 60-minute synthetic mode.

  transcript_bad_intervals.json       — error: end ≤ start.
  transcript_bad_empty.json           — error: empty utterance list.

  transcript_warn_beyond_session.json — warning: end is past the session length.
  transcript_warn_overlap.json        — warning: overlapping intervals.
  transcript_warn_empty_text.json     — warning: empty utterance text.
  transcript_warn_negative_start.json — warning: negative start_s.

If you also enable "append the example from transcript.example.json", validation
covers the merged list.
